# Assignment 3

Simple Node.js project demonstrating a Student model, in-memory data, and analytics helpers.

Files:
- `main.js` — program entry that fetches students and prints analytics.
- `models.js` — `Student` class with immutable `id`, course management, and average calculation.
- `database.js` — in-memory sample data and `fetchStudents` (simulated async).
- `analytics.js` — utility functions: `calculateClassAverage`, `findTopStudent`, `filterStudents`.

Run
```
node main.js
```
